## 核心洞察:一位創作者的三套視覺武器

**這位創作者不是「有一個風格」,而是「有一個風格系統」**——每種內容類型配一種視覺語言。

| 風格 | 代表貼文 | 對應目的 | 情緒定位 |
|------|--------|--------|--------|
| **① 牛皮紙手寫系**(文藝深度) | Prompt 系列 / 2026 IG 演算法 | 講透 + 養熟 | 慢讀、有溫度、值得收藏 |
| **② 黑板粉筆系**(工程實用) | Claude 自動化單張 | 拓新 + 承接(換名單) | 能量、教學感、立刻能用 |
| **③ 編輯設計系**(專業指南) | 封面 5 關 9 張 | 講透(專業權威) | 冷靜、專業、指南感 |

**這是「內容 × 目標 × KPI × 視覺」的四維策略**——大多數創作者只有一套視覺,他用三套打不同的球。

## 第一系列:5 張 Prompt 卡

**視覺風格**:牛皮紙 + 藍色手寫字 + 圓形頁碼章 + 底部藍色標籤條
**用途**:「Claude IG Prompt 系列」——一套從無到有的內容生產線
**核心邏輯**:5 個 prompt 是串接式,不是獨立卡片

### Prompt 1 — 策略層(規劃)

**角色**:10 年經驗的資深 IG 成長策略師,服務過 50 個從 0 到 10 萬的帳號

**任務**:
- 分析利基市場,找出 7 個最飽和的內容模式
- 產出 10 個打破這些模式的原創貼文創意
- 每個創意包含 5 個項目:核心概念 / 開場 Hook / 最適合格式 / 為什麼新鮮 / 為什麼會被收藏
- 排出最有潛力的前 3 名

**變數**:利基市場(Niche)/ 受眾(Audience)/ 目標(Goal)

### Prompt 2 — Hook 層(吸引)

**角色**:專精 IG 病毒式傳播的頂級文案寫手,寫過的 Hook 平均讓完播率提升 40%

**任務**:針對創意生成 15 個 Hook,平均分配到 5 種類型 × 每種 3 個:
- 好奇心型
- 反向思考型
- 情緒張力型
- 具體數字型
- 低調權威型

**規則**:
- 不能用標題黨或誇張承諾
- 讀起來要像真人說話
- 長度 15 字內
- 排出前 5 名並說明強在哪

**技巧洞察**:
- 用「配額制」逼多樣性
- 用「反面規則」控品質
- 用「字數上限」防灌水

### Prompt 3 — 格式層(製作)

**角色**:IG 無臉內容策略師,專門幫不想露臉、沒設備的創作者做高觸及內容

**任務**:把創意轉化成 3 種無臉版本:
- 版本一:輪播貼文
- 版本二:純文字 Reel(螢幕文字,無需配音)
- 版本三:無聲視覺貼文(靜態或慢動作)

**每版本必須提供 5 個欄位**:
1. 完整內容結構
2. 螢幕上的文字(逐字稿)
3. 視覺方向(背景/字型/顏色)
4. 說明文案(caption)
5. CTA(結尾引導)

**限制**:不露臉、不配音、不跟風、不需複雜剪輯

**技巧洞察**:
- 把「限制」當設計原則,不是障礙(Constraint-Driven Design)
- 一個創意 → 三種格式版本(A/B/C 測試思維)
- 5 個必填欄位 = 拍攝團隊收到就能執行的簡報

### Prompt 4 — 留存層(演算法優化)

**角色**:IG 留存優化專家,把普通內容改寫成讓人看完、收藏、二刷的版本

**任務**:改寫內容,最大化 4 個指標:
- ① 觀看時長(捨不得滑走)
- ② 完播率(每一行帶動下一行)
- ③ 收藏數(之後會用到)
- ④ 分享數(要傳給朋友看)

**改寫規則**:
- 刪掉所有弱句、廢話、填充詞
- 每一行結尾要讓人想繼續讀
- 保持自然口語、不推銷
- 改完後條列說明改了什麼、為什麼

**技巧洞察**:
- Metric-Driven Prompting(把「感覺」翻成「數字」)
- Bucket Brigade(接力桶技巧)
- Meta-Prompting(讓 AI 邊做邊教你)

### Prompt 5 — 品牌層(人格塑造)

**角色**:頂級品牌定位顧問,幫個人 IP 在不自吹自擂下建立專業權威感

**任務**:改寫內容,做到:
- 不像在教人、不像大師在說話
- 不炫耀數字、不刻意強調成就
- 不顯得自大或高高在上
- 讀起來像一個真正懂的人在說真話

**輸出 3 個版本**:
- 版本一:優雅版(有質感、有留白)
- 版本二:直接版(短句、快節奏)
- 版本三:高端感版(精準用字、低調但有份量)

**技巧洞察**:
- Anti-Prompting(反向提示)——用禁止清單比正向指令更精準
- 從「產出型 prompt」躍升到「語氣型 prompt」
- P4 + P5 必須合用:單用 P4 = 爆款廢文;單用 P5 = 精緻孤獨

### Prompt 系列的完整串接邏輯

```
[Prompt 1] 策略層 → 產出 10 個原創貼文創意
       ↓ 選 1 個
[Prompt 2] 文案層 → 為這 1 個創意寫 15 個 Hook
       ↓ 選 1 個 Hook
[Prompt 3] 製作層 → 把創意 × Hook 轉成 3 種無臉格式
       ↓ 選一個版本
[Prompt 4] 留存層 → 針對 4 個 KPI 改寫到極致(演算法優化)
       ↓
[Prompt 5] 品牌層 → 校正語氣為「有權威感但不炫耀」
       ↓
    可發布的成品
```

## 第二系列:2026 IG 演算法

**視覺風格**:牛皮紙暖黃 + 藍色手寫字 + 灰底圓形頁碼 + 右下角小插圖
**標題**:「2026 IG 演算法,真的把輪播貼文救回來了嗎...」
**核心價值**:建立完整的 IG 演算法心智模型

### 第 3 張:一篇內容被放大前,要先過 4 關

```
【① 推薦資格】內容原創 + 畫質清楚 + 帳號健康 → 進候選池
       ↓
【② 主題匹配】AI 看懂你在講什麼 + 找到可能有興趣的人
       ↓
【③ 行為預測】停留 / 分享 / 收藏 / 留言 / 重播
       ↓
【④ 同池競爭】表現高於相似內容 → 曝光繼續放大
```

**關鍵數據**:Meta 公開資料顯示,2025 Q4 美國 IG 推薦內容,75% 來自原創貼文。

### 第 4 張:IG 同時跑 5 套不同的場內規則

| 場合 | 核心信號 | 誰在看 | 目標 |
|------|--------|--------|------|
| **動態牆** | 關係 + 興趣 | 現有追蹤者 | 深化關係 |
| **限時動態** | 關係強度 | 死忠粉絲 | 維持親密感 |
| **Reels** | 陌生發現 | 完全陌生人 | 破圈爆量 |
| **Explore** | 興趣貨架 | 興趣相符陌生人 | 精準吸粉 |
| **Search** | 主動需求 | 有目的的搜尋者 | 轉換成交 |

**策略洞察**:根據目標選擇要優化的場,而不是同一套內容丟到 5 個場。

### 第 5 張:2026 的競爭,從格式紅利走到行為訊號

**6 個正訊號**(愈往下權重愈重):
- ⏳ 停留 / 看完
- 🔖 收藏 / 回查
- 💬 留言 / 追蹤
- ✈️ 分享 / 私訊 ← 最高等級
- 🔄 重播 / 再滑一遍

**1 個負訊號**:
- 👤 快速略過 / 不感興趣 ← 一票否決

**核心真理**:
> IG 沒有公開固定權重,也沒有單一神指標。
> 它要判斷的只有一件事:**這篇內容,對這個人有沒有價值?**

**戰略啟示**:
- 一個「快速略過」的殺傷力 ≈ 三個「按讚」的加分
- 精準小眾永遠打贏泛用大眾
- 「對這個人」四個字是關鍵——不是「對大眾」

### 第 6 張:輪播貼文重新有機會,靠的是 3 種行為優勢

- **① 每滑一頁 = 延長停留與閱讀深度**
- **② 流程 / 清單 / 比較表 = 天然收藏與分享理由**
- **③ 資訊可回查 = 長尾流量(3-14 天穩定推薦)**

**警告**:
> 10 張廢話依然是 10 張廢話。
> 每一頁都要讓人得到一個東西,演算法才有訊號可看。

**輪播寫作黃金法則**:把輪播想成 10 張可獨立成立的知識卡片,不是「一篇長文切 10 段」。

### 第 7 張:Reels 還有用,只是紅利沒那麼甜了

**Reels 依然適合**:
- 打陌生觸及
- 示範動作與產品
- 承載情緒、故事與前後對比

**Reels 現在在意的 4 個 KPI**:
- 開頭能不能留人
- 平均觀看時間
- 完播 / 重播
- 觀眾願不願意分享

**市場現況**:短影音供給暴增 + 觀眾滑得更快 = 現在做 Reels 比 2022 更像競技場。

**神級結尾**:
> 所以別停拍,但先停止什麼題目都硬拍。

### 第 8 張:Hashtag 還活著,只是職位降成配角

**AI 現在能讀的 5 個訊號源**:
1. 帳號資訊(bio、名稱、歷史發文)
2. 內文(NLP 解讀 caption)
3. 畫面文字(OCR 讀取圖片/影片文字)← 關鍵
4. 影片內容(Computer Vision)
5. 使用者行為(反向推論主題)

**關鍵字放置優先順序(權重由高到低)**:
- ① 名稱與簡介 ← 最高權重(24 小時 SEO)
- ② 封面標題 ← AI OCR 首先讀取
- ③ 內文前兩行 ← 「查看更多」點擊前
- ④ 畫面字幕 / 口白 ← 影片型內容
- ⑤ 少量、精準、真的相關的 Hashtag ← 最低權重

**核心警告**:
> 塞 30 個熱門標籤,完全沒有意義。

### 第 9 張:2026 的內容策略——先分工,再看對的 KPI

**這是整個系列的作戰地圖**(對應行銷漏斗 AARRR):

| 目標 | 主打場 | 該看的 KPI |
|------|--------|-----------|
| **拓新** | Reels / Explore | 非粉觸及、平均觀看時間、留存、分享 |
| **講透** | 動態牆 / 輪播 | Views、觸及、收藏、分享、個人檔案活動 |
| **養熟** | 限時動態 | 完整觀看、退出、貼紙互動、回覆、私訊 |
| **承接** | Search / 個人檔案 | 檔案瀏覽、追蹤、連結點擊、詢問 |

**核心公式**:同一個主題,可以拆成四種內容。

**警告金句**:
> 別再只用按讚數,判斷所有格式的生死。

## 第三份:Claude 自動化

**視覺風格**:深色黑板底 + 粉筆手寫字 + 陶土機器人吉祥物 + 高資訊密度
**用途**:單張爆款(拓新 + 換名單 CTA)
**互動數據**:讚 205 / 留言 476 / 收藏 147(留言是讚的 2.3 倍——CTA 設計成功)

### 9 個鈎子公式(頂級文案寫手的完整武器庫)

| # | 公式名 | 心理機制 |
|---|-------|--------|
| ① | 好奇心缺口 | 開一道縫讓人想看 |
| ② | 具體數字 | 精確數值建立信任 |
| ③ | 損失趨避 | 錯過就是虧 |
| ④ | 身分認同 | 同類人在做的事 |
| ⑤ | 強烈對比 | 反差要夠大 |
| ⑥ | Before-After | 放大改變幅度 |
| ⑦ | 社會認同 | 多數人的選擇 |
| ⑧ | 意外性 | 稍微背叛期待 |
| ⑨ | 低門檻 | 讓人覺得我也行 |

**對應心理學經典**:
- ①②③ = Kahneman《快思慢想》認知偏誤
- ④⑤⑥⑦ = Cialdini《影響力》說服六原則
- ⑧⑨ = BJ Fogg / Nir Eyal 行為設計學

### 混合黃金規則

> 一次最多混兩個公式 — 數字 + 情緒 點擊率最高(混三個反而失效)

**認知負載理論**:
- 混 1 個 → 訊息單純但可能無力
- 混 2 個 → 互補加乘,大腦剛好能處理 ✅
- 混 3 個以上 → 大腦當機,直接滑走

**「數字 + 情緒」= 黃金組合**——左右腦同時被打中 = 停留最久。

```
用 [主題] 設計 5 句輪播第一句。
• 先定義讀者藏起來的 1 個不安或渴望
• 從 9 公式挑「不同的 2 個」疊加使用
• 每句標註(用了哪 2 個公式 · 停下的心理)
• 補充 1 句誘發收藏與分享的理由
• 禁止誇大

[主題]:
```

### 神級 caption 示範(自己就是 Hook 公式的示範)

## 第四系列:封面 5 關

**視覺風格**:純白/米白底 + 深藍主標 + 亮紅強調 + 淡綠底條列(編輯設計風)
**標題**:「輪播貼文沒人看?先別急著怪內容...」
**核心價值**:設計基礎課的 IG 版本

### 目錄(第 3 張)——5 關預告

| 關卡 | 檢核問題 | 對應設計原則 |
|------|--------|-----------|
| **01 可讀性** | 縮圖還看得懂嗎? | Legibility(易讀性)|
| **02 圖像** | 拿掉標題還猜得到嗎? | Visual Hierarchy(視覺分工)|
| **03 鉤子** | 一張只講一件事 | Focus Principle(焦點法則)|
| **04 對比** | 主標先跳出來嗎? | Contrast(對比)|
| **05 品牌** | 不看帳號也認得出你嗎? | Brand Consistency(品牌一致性)|

**順序邏輯**:由外而內、由生死到品味的漏斗——過不了 01,談 05 就是奢侈。

### 01 可讀性(第 4 張)

**主標**:主標要大到,滑過去也看得懂。

**核心數據**:**25%** ← IG 縮圖佔原尺寸的比例(1080×1080 → 270×270)

**3 條規則**:
- ▶ 縮圖測試:縮小後,主標仍然一眼看懂,才算過關
- ▶ 主標 2-3 行
- ▶ 一頁 1 個閱讀焦點

**心態轉換**:
- ❌ 觀眾會停下來看我這張圖
- ✅ 觀眾正在快速滑動,我的圖有 0.5 秒機會被讀懂

### 02 圖像(第 5 張)

**主標**:拿掉標題,你還猜得到主題嗎?

**核心宣言**:圖片不是裝飾。它要先替你講半句話。

**圖像要傳達的 3 個維度**(至少 1 個):
- **情境**(Situation):這是在什麼場景?
- **對象**(Character):這是給誰看的?
- **結果**(Outcome):帶來什麼改變?

**核彈級警告**:
> 漂亮的通用圖很安全,也最容易被忘記。

**Visual-Verbal Complementarity**:
- ❌ 圖像=裝飾(0句)+ 文字(1句)= 效率 50%
- ✅ 圖像(半句)+ 文字(半句)= 效率 200%(1+1>2)

### 03 鉤子(第 6 張)

**主標**:一張封面,只講一件事。

**核心對照**(Feature vs Benefit):

| 主題寫法(❌)| 結果寫法(✅)|
|------------|------------|
| 輪播封面設計技巧 | 輪播沒人看?先檢查這 5 個地方。|
| AI 提示詞教學 | AI 效率翻 10 倍,只用這 3 個 prompt |
| 讀書筆記方法 | 讀 100 本忘 90 本?筆記做錯了 |

**3 元素檢核**(至少出現 2 個):
- **對象**:誰要看?
- **痛點**:遇到什麼問題?
- **明確結果**:會得到什麼?

**結果寫法的心理學結構**:
```
[提出讀者的痛點/現況] + [承諾具體的改變/答案]
```

### 剩下 2 張推測(04 對比 + 05 品牌 + 09 收尾)

- **04 對比**:主標先跳出來嗎?(視覺重心 + 5 秒測試法)
- **05 品牌**:不看帳號也認得出你嗎?(色彩指紋 + 字型指紋 + 版型指紋)

## 跨系列的頂級洞察

### 洞察 1:三個系列合起來 = 完整的內容工程系統

```
【WHY】2026 IG 演算法(10 張)→ 讓你理解為什麼要這樣做
【HOW】Prompt 系列(5 張)     → 讓你有工具去做
【EXECUTION】封面 5 關(9 張)  → 讓你知道成品怎麼判斷
```

**每個系列服務不同的漏斗階段**:
- 演算法系列 = **講透 + 養熟**(建立信任、培養死忠)
- Claude 自動化 = **拓新 + 承接**(換名單)
- 封面 5 關 = **講透**(專業權威)

### 洞察 2:9 個鈎子公式 + 3 元素檢核 = 標題寫作完整系統

**寫任何標題前的完整檢核流程**:
1. 用「結果寫法」開頭(不是「主題寫法」)
2. 包含至少 2 個元素(對象 / 痛點 / 明確結果)
3. 疊加恰好 2 個公式(數字 + 情緒最強)
4. 通過縮圖可讀性測試

### 洞察 3:6+1 訊號 × Prompt 系列的完美對應

| Prompt | 主要觸發的行為訊號 |
|--------|----------------|
| P1 策略層 | 找到「對觀眾有價值」的主題 → 避免快速略過 |
| P2 Hook | 第 3 秒抓住 → 提升「停留」 |
| P3 格式 | 3 版本適配不同場 → 提升「看完」 |
| P4 留存 | 直接對準 4 個 KPI → 提升「收藏 + 分享」 |
| P5 品牌 | 建立信任 → 提升「追蹤 + 私訊」 |

**這 5 個 Prompt = 完美對應 6+1 行為訊號**——這位創作者是先讀懂 IG 的行為訊號模型,再倒推該做什麼 prompt。

### 洞察 4:輪播 vs Reels 完整戰略對照

| 維度 | 輪播(2026 復活)| Reels(2026 降溫)|
|------|--------------|--------------|
| 最擅長的行為訊號 | 停留 / 收藏 / 分享(回查)| 完播 / 分享 / 陌生觸及 |
| 最適合的內容類型 | 流程 / 清單 / 比較 / 觀點宣言 | 動作示範 / 情緒故事 / 前後對比 |
| 最大優勢 | 長尾流量(3-14 天)| 破圈能力(觸達陌生人)|
| 最大陷阱 | 「10 頁廢話還是廢話」| 「隨便拍就爆」時代結束 |
| 決勝時刻 | 前 3 頁能不能勾人繼續滑 | 前 1 秒能不能不被滑走 |
| 適合的創作者 | 有累積思考、有系統知識 | 有鏡頭感、有戲、有動作可拍 |

### 洞察 5:Meta 教學——內容本身是教學的示範

這位創作者的所有教學都遵循「Practice What You Preach」:
- 教 Hook 公式 → 用 Hook 公式寫 caption
- 教「一張只講一件事」→ 卡片本身只有一個焦點
- 教「主標要大」→ 卡片的主標就是超大字級
- 教「結果寫法」→ 每個系列的標題都是結果寫法

**這是最高等級的內容行銷:教學本身就是產品示範**。

## 個人可執行的檢核清單

### 【發文前必過】5 大檢核

**① 主題檢核(對應 Prompt 1)**
- [ ] 我是否有明確的利基市場?
- [ ] 這個主題是否對特定人群有價值?(不是「對大眾」)

**② 標題檢核(對應鉤子 9 公式 + 3 元素)**
- [ ] 我用了「結果寫法」而不是「主題寫法」?
- [ ] 標題包含至少 2 個元素(對象/痛點/明確結果)?
- [ ] 疊加了恰好 2 個 Hook 公式(推薦:數字 + 情緒)?
- [ ] 字數在 15 字內?

**③ 封面檢核(對應 5 關)**
- [ ] 【可讀性】縮圖 270×270 還讀得懂主標?
- [ ] 【圖像】拿掉標題,還能猜到主題?
- [ ] 【鉤子】一張只講一件事?
- [ ] 【對比】主標 3 秒內先跳出來?
- [ ] 【品牌】不看帳號名,能認出這是我的作品?

**④ 內容檢核(對應 Prompt 4)**
- [ ] 刪掉所有弱句、廢話、填充詞?
- [ ] 每一行結尾能勾下一行?
- [ ] 沒有推銷語氣?

**⑤ 品牌檢核(對應 Prompt 5)**
- [ ] 不像在教人?
- [ ] 沒炫耀數字?
- [ ] 讀起來像真人而不是 AI?

### 【發文後 24 小時】行為訊號自評

按照對應的**目標場合**,只看該場的 KPI:

**如果目標是拓新(Reels / Explore)**:
- [ ] 非粉觸及比例?
- [ ] 平均觀看時間?
- [ ] 留存率?
- [ ] 分享數?

**如果目標是講透(輪播)**:
- [ ] Views / 觸及?
- [ ] 收藏數?← 專業信任的最強訊號
- [ ] 分享數?
- [ ] 個人檔案活動?

**如果目標是養熟(限動)**:
- [ ] 完整觀看率?
- [ ] 貼紙互動數?
- [ ] 私訊回覆數?

**如果目標是承接(Search / 檔案)**:
- [ ] 檔案瀏覽數?
- [ ] 新追蹤數?
- [ ] 連結點擊數?

**永遠不看**:單純的按讚數(2026 已是無意義指標)

### 【內容策略】週度規劃模板

```
週一:【拓新】Reel  → 一個高衝擊 Hook 主題(0.8 秒抓人)
週三:【講透】輪播  → 一個知識框架(流程/清單/比較表)
週五:【養熟】限動  → 互動貼紙(投票/問答/滑桿)
週日:【承接】檔案優化 → 檢查 bio、pin 貼文、精選限動
```

**同一主題,4 種內容,4 套 KPI**——一週產出 4 篇,只花 1 個主題的思考成本。

## 後記

**這位創作者(@ericchi_6666)最厲害的地方**:

1. **系統思考**:他的每個 prompt / 每個系列都在服務同一個內容工程矩陣
2. **視覺紀律**:三套風格對應三種目的,不混用
3. **Meta 示範**:所有教學內容本身就是教學規則的示範
4. **反 AI 味**:雖然大量用 AI,但呈現出的內容有強烈個人風格

**如果你要學怎麼做知識型內容,這 25 張貼文(5+10+1+9)比 100 個「教你經營 IG」的帳號都值得研究**。

**最終洞察**:
> Prompt 不是「魔法咒語」,是「把你腦中的暗知識翻譯給 AI 聽」。
> 你越懂一個領域,你寫的 prompt 就越能榨出 AI 的極限。
