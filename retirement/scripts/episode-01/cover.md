## 一、設計 DNA（頻道視覺系統）

### Palette

| 色票 | HEX | 用途 |
|---|---|---|
| **Paper（紙）** | `#C9D0D6` | 底色 · 煙燻藍灰 |
| Paper-deep | `#B8C1C9` | 次要區塊 |
| **Ink（墨）** | `#1A2130` | 主標 · 深板岩藍 |
| Ink-soft | `#3C4759` | 副標 |
| **Accent（強調）** | `#A83C2C` | 數字亮點 · 印章 · 深磚紅 |
| Accent-deep | `#832B1E` | 印章邊框 |
| Rule | `#95A0AC` | 分割線 · 冷煙燻 |
| Mute | `#5E6A78` | 落款字灰 |
| Shell | `#0E1116` | 背景框 · 近黑 |

**為何是煙燻藍灰**：
- 避開 AI 預設「奶油底 + 硃砂紅」的疲勞美學
- 冷色系傳達「冷靜、計算、專業」的財經頻道基調
- 靈感來源：舊版《華爾街日報》紙本、建築師藍圖紙、摩天大樓黃昏

### Typography

- **主標**：`PingFang TC / Noto Sans TC` 900 weight · super heavy · line-height 0.94
- **內文**：同 family · 500 weight
- **數字（等寬）**：`SF Mono / Menlo / ui-monospace` · 用於頁碼、CAGR、+308%
- **禁用**：襯線字體、圓體、手寫字
- **理由**：財經頻道要「權威 + 誠實」而非「文藝 + 花俏」

### Layout Grid

- **尺寸**：1080 × 1350（IG 4:5 首頁比例）
- **內距**：7.5% × 7.5% × 7%
- **5 段格結構**（grid-template-rows: auto 1fr auto auto auto）：
  1. Header：眉標（左）+ 頁碼（右）
  2. Hero：主標題（1fr 佔用剩餘空間）
  3. Ledger：兩行數據對照表
  4. Tagline：副說明
  5. Footer：帳號 + SWIPE

### Signature 元素

- **紅色圓形印章**（右邊中段浮貼）
  - 位置：`right: 6.5%; top: 32%`
  - 尺寸：`clamp(70px, 11vw, 130px)` 動態縮放
  - 旋轉：`-11deg`（略歪的手蓋章感）
  - **文字系統**（每集換）：
    - EP.01「算過 · 認錯」
    - EP.02「算過 · 拆完」（殺基金拆解時）
    - EP.03「算過 · 證偽」（打話術時）
    - EP.04「算過 · 對帳」（做回測時）
    - 依此類推
- **帳本橫線紋理**：極淡的水平線每 40px，模擬會計簿紙
- **冷色 vignette**：右下角有微微的暗角，讓紙面有立體感

### 資訊架構

**首頁必備 4 個元素**（依權重）：
1. **一句話 Hook**（占版面 30%）
2. **兩行數據對照**（占版面 20%）—— 純用數字說故事
3. **紅色印章**（占版面 8%）—— 品牌指紋
4. **SWIPE 指引**（占版面 3%）

## 二、Iteration Log · 我們怎麼一步步改到現在

### Attempt 1 · 奶油底 + 硃砂紅 + 藍字
- Palette: `#F2EDE1` cream + `#0F1D3A` navy + `#D93B26` red
- 主標「數據打臉」加了紅色斜下劃線做強調
- **回饋**：「紅字下面畫紅線，不清楚」+「奶油底一看就知道是 AI 做的」
- **問題**：中了 [artifact-design skill 明列的 AI 預設陷阱](../../editorial/ericchi-ig-masterclass.md#跨系列的頂級洞察)：
  > "warm cream (#F4F1EA) with a serif display and terracotta accent" —— AI 生成設計最容易的路徑

### Attempt 2 · 拿掉紅色斜下劃線
- 只保留「數據打臉」四個字為紅色
- **改善**：字面乾淨、閱讀順暢
- **仍然的問題**：奶油底 + 硃砂紅組合本身還是太 AI

### Attempt 3 · 換成煙燻藍灰 + 深磚紅（目前定稿）
- Paper: `#F2EDE1` → **`#C9D0D6`**（煙燻藍灰）
- Accent: `#D93B26` → **`#A83C2C`**（深磚紅，成熟）
- Ink: `#0F1D3A` → **`#1A2130`**（更中性的深板岩）
- Rule: 暖米 → **冷煙燻藍**
- 質感層：柔光徑向漸層 → **極淡帳本橫線 + 冷色 vignette**
- **結果**：從「網頁編輯」變成「翻開財經筆記本」的觸感

### Attempt 4 · 微調文案
- 「我上週建議的部位」→「**我建議買入的部位**」
- 理由：「上週」在標題已提過，這裡再重複顯得冗；改「買入」更聚焦於「行為」

## 三、如何匯出成圖

### 方法 A · Chrome DevTools（推薦，最乾淨）
1. 開啟 `cover-p1.html` 於 Chrome
2. `Cmd+Option+I` 打開 DevTools
3. `Cmd+Shift+P` 打開命令列
4. 輸入 `Capture node screenshot`
5. 選中 `<article class="cover">` 元素
6. 得到**去背 + 精準像素**的 PNG

### 方法 B · Retina 高解析
- DevTools → Toggle device toolbar → 設定 device pixel ratio 為 3
- 再用方法 A 截圖 → 3× Retina 品質

### 方法 C · 快速
- Mac `Cmd+Shift+4` 拉框截圖

## 五、給未來自己的提醒

1. **每次做新集封面，先看這個 palette，不要再重新想配色** —— 保持頻道視覺一致才會有品牌感
2. **印章的第二個字（認錯/拆完/證偽...）就是那集的「精神」** —— 選字要慎重
3. **不要加更多視覺元素了** —— 現在的極簡是刻意的，加圖示、加插畫都會破壞氣質
4. **假日發文才用完整輪播 10 頁** —— 平日改用單圖或 3 頁短輪播降低製作成本
