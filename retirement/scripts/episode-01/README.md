## 為什麼是第一集？

在 [`../../editorial/channel-playbook.md`](../../editorial/channel-playbook.md) 的素材倉庫裡，這支被排 ⭐⭐⭐ 最優先，理由：

1. **稀缺性**：台灣財經圈**幾乎沒有 KOL 敢公開承認錯誤**。一支自我打臉當開台，直接定調頻道「不是神，是拿計算機的人」。
2. **話題性**：2330 是全民股，人人有感。
3. **雙面示範**：既示範「歷史分位法」，也示範「歷史分位法的失效條件」—— 一次教會觀眾兩個工具。
4. **Kill Condition 天然存在**：這集本身就是打上一集的臉，直接示範「我怎麼發現自己錯」的過程。

## Kill Condition（何時該重新檢視整套定位）

- 這一集**收藏率 < 3%** → 主題方向可能沒抓對，回頭改利基
- 這一集**分享率 < 1%** → 內容沒觀點，加強反直覺洞察
- 連續 3 集**新粉絲 < 20** → 拓新內容不足，Reels 比例要拉高
- **業配邀約出現時**：拒絕。一旦收錢就失去頻道核心。
