# Part 0 · 為什麼 IG SEO 是被忽略的槓桿

## 財經 KOL 的兩種流量來源

1. **演算法推薦**（Reels / Explore）· **短期爆量 · 但撐 24-72 小時就冷**
2. **搜尋 + 主頁 discovery** · **長期滲透 · 撐 6-24 個月**

**多數 KOL 只做第一種**（追爆款）。**通無法師的機會 = 把第二種做到極致**。

## 為什麼 SEO 對通無法師特別重要

- **目標觀眾（40-55 歲）搜尋行為 > 滑 timeline**（他們不追熱門，他們主動查）
- **教典型內容適合被搜尋**（藥師 / 邵雍 / 殺基金 都是搜尋詞）
- **不變現的頻道**特別需要「別人主動找到你」的機制（不靠付費投放）
- **3 年後退休** = 頻道要能**自動被搜尋到 5-10 年**，不能只靠當下熱度

## IG SEO 的 3 個時間層

- **當下**（發文後 24 hr）· 靠演算法推薦
- **中期**（1-6 個月）· 靠關鍵字命中 · Explore
- **長期**（6-24+ 個月）· 靠 SEO + 品牌搜尋 · **這是通無法師的主戰場**

# Part 1 · 5 支柱深度執行

## 🏛 支柱 1 · Profile SEO（一次設定，永久受益）

**核心邏輯**：**IG 內建搜尋 + Google 索引** 都會爬你的 Profile 元素。

### 1.1 · 顯示名稱（權重最高）

**現行版**：`通無法師 · back2void`

**為什麼這樣寫**：
- **主品牌名放前**（中文 SEO）
- **·（點）+ 英文** = 讓外語圈也能搜到
- **不超過 30 字元**（IG 限制）

**Checklist**：
- [ ] 名稱是否包含 1 個核心關鍵字（本頻道 = 「通無法師」）
- [ ] 有沒有廢字（例：「/」「⚡」等符號會扣 SEO 分）
- [ ] 每次改名冷卻 14 天 · 頻繁改會被降權

### 1.2 · @ handle（第二權重）

**現行版**：`@back2void`

**為什麼這樣寫**：
- **英文短、好記、好打字**
- 有明確**動詞含義**（back to void = 回到虛無）
- 一輩子不改（改 handle 舊連結全失效）

**Checklist**：
- [ ] handle 長度 < 15 字元（好記憶）
- [ ] 沒有底線 · 沒有數字（顯得業餘）
- [ ] Twitter / Threads / Substack / GitHub / TikTok 都預留同一 handle

## 📝 支柱 2 · Content SEO（每篇要做）

**核心邏輯**：**IG 的 AI 會讀你的 caption / ALT text / 影片字幕 / 圖片文字**。每個都是 SEO 機會。

### 2.1 · Caption 前兩行（權重最高）

**規則**：
- **關鍵字放前 2 行**（「查看更多」按鈕之前）
- 主 Hook + 1-2 個核心關鍵字

**Checklist**：
- [ ] 前 2 行有 ≥ 2 個關鍵字（例：「台積電」「殺基金」「PER」「藥師」）
- [ ] 沒有 spam 感（塞太多關鍵字反效果）
- [ ] 有 Hook · 不是純資訊

### 2.2 · ALT Text（超高權重 · 但被忽略）

**每張圖都要填 ALT text**（IG 專業帳號後台可設）

**為什麼**：
- **IG 的 AI 用 ALT 判斷圖片主題**（OCR + NLP）
- **視覺障礙讀者用 ALT 讀出來**
- **Google 索引 IG 貼文靠 ALT**

**Checklist**：
- [ ] 每張輪播圖填 20-30 字 ALT text
- [ ] ALT 包含**該頁核心關鍵字**（不是 caption 複製）
- [ ] 例：P1 ALT = 「台積電 5 年漲 3 倍 · 通無法師 EP.01 · 藥師第五願恢復清淨」

### 2.3 · 位置標記（每次都加）

**每次發文加地點 = 台灣 · 台北市**

**為什麼**：
- 讓地區搜尋能找到你
- 40-55 歲觀眾多用 Explore 附近功能

**Checklist**：
- [ ] 主集加「台北市」or「台灣」
- [ ] 冷啟動期（Days 1-30）每篇都加

### 2.4 · 主題導向 vs 心情導向

**永遠**用主題導向：
- ✅ 「台積電 PER 99 分位」（可搜尋）
- ❌ 「今天心情不好」（無法搜尋）

**Checklist**：
- [ ] Caption 第 1 行有可搜尋主題詞
- [ ] Cover text 有主題詞（IG 有 OCR）

### 2.5 · 圖片內文字（OCR 可讀）

**IG AI 會用 OCR 讀你封面上的字** —— 這也算 SEO！

**Checklist**：
- [ ] Cover text 用**清楚可讀字體**（不用花俏字型）
- [ ] Cover text 含 1-2 個關鍵字（例：「殺基金」「台積電」「藥師」）
- [ ] 不要用**手寫字**（OCR 讀不到）

## 📈 支柱 4 · Discoverability（行為訊號累積）

**核心邏輯**：**IG 演算法用觀眾行為判斷你「值得被推薦」**。

### 4.1 · 4 大行為訊號（依權重）

| 訊號 | 權重 | 通無法師怎麼拉 |
|---|---|---|
| **分享（Send）** | ⭐⭐⭐⭐⭐ | Pinned Comment 明說「傳給家人」 |
| **收藏（Save）** | ⭐⭐⭐⭐ | 每篇 P7 有可截圖金句 · 每篇 P8 藥師偈子 |
| **停留時間** | ⭐⭐⭐⭐ | Bucket Brigade 每頁拉下頁 |
| **留言** | ⭐⭐⭐ | P10 具體提問 · Pinned Comment 引導留言 |

### 4.2 · 負面訊號（要避免）

| 訊號 | 傷害 |
|---|---|
| **快速略過（Swipe past）** | 一票否決 · 演算法立刻降推 |
| **取消追蹤** | 短期內大量 → 演算法認為內容變差 |
| **檢舉** | 就算誤檢舉也會扣分 |

### 4.3 · 穩定發文（節奏訊號）

**IG 給「規律發文」的帳號權重加分**

**Checklist**：
- [ ] 週日 20:00 主集（不遲）
- [ ] 週三 12:00 Reel（不遲）
- [ ] 每日至少 1 則限動（Days 15 之後）
- [ ] 每月**不消失** > 3 天（會被降權）

### 4.4 · 互動高峰時段管理

**發文後前 4 小時決定演算法評分**

**Checklist**：
- [ ] 發文後 30 分 · 檢查前 5 個留言 · 回覆
- [ ] 前 4 hr 每 30 分回一輪
- [ ] 前 24 hr 每 2-3 hr 回一輪
- [ ] 主編**發文當晚不出門** = 認真回互動

## 🌐 支柱 5 · External Backlink SEO（跨平台反向助推 · 通無法師專屬）

**核心邏輯**：**IG 的搜尋 rank 會被外部連結加分**（雖然 Meta 不公開，但實測有效）。

### 5.1 · Threads 反向助推

**Checklist**：
- [ ] Threads 每篇貼文**帶主 IG 連結**（自然嵌入）
- [ ] Threads 個檔 bio 標 IG @back2void
- [ ] Threads 貼文分享數 → IG 演算法識別為「被引用」

### 5.2 · Substack 反向助推

**Checklist**：
- [ ] 每封電子報**至少 1 個 IG 主貼連結**
- [ ] Substack about 頁提及 IG
- [ ] 電子報開信率高的信 → Substack 演算法推薦其他人 → 帶流量給 IG

### 5.3 · GitHub 反向助推

**Checklist**：
- [ ] 每個 Repo README 開頭有「來自通無法師 @back2void」+ 連結

### 5.4 · Google Search 埋點

**目標**：讓別人 Google「通無法師」時，前 5 頁都是自己的內容。

**Checklist**：
- [ ] Substack about + 首篇正式介紹「通無法師」定位（Google 會索引）
- [ ] GitHub Repo README 描述含品牌關鍵字

- [ ] 每季發 1 篇「What is 通無法師」型內容到 Substack 或 Medium

### 5.5 · YouTube 反向 SEO（未來 · Season 3 之後）

**Checklist**：（未來規劃）
- [ ] YouTube channel description 提 IG
- [ ] YouTube 影片開頭 3 秒有 @back2void watermark
- [ ] YouTube 影片描述附主 IG 貼連結

**這個支柱是全台財經 KOL 最少做的** —— **通無法師的第二護城河**。

**通無法師對應內容**：**拆話術系列** · **殺基金 X 光片**

### 動機 B · 家人保護搜尋（Persona B 張太太型）
**典型搜尋**：
- 「怎麼跟父母講不要買儲蓄險」
- 「爸媽被詐騙怎麼辦」
- 「保單真相」
- 「業務推銷話術」

**通無法師對應內容**：**觀眾投稿系列** · **保單拆解**

### 動機 C · 學習成長搜尋（Persona C 陳老師型）
**典型搜尋**：
- 「0050 vs 006208 差別」
- 「被動投資入門」
- 「藥師經投資」（罕見但存在！）
- 「邵雍 皇極經世」

**通無法師對應內容**：**心法系列** · **對照系列**

## 關鍵字命中優先順序

**每篇貼文至少命中 3 級關鍵字**：

| 層級 | 例 | 出現位置 |
|---|---|---|
| **一級**（主要搜尋詞） | 台積電 · 殺基金 · 保單 | Caption 第 1 行 · Cover Text |
| **二級**（差異化詞） | 藥師 · 邵雍 · 通無 | Caption 中段 · Hashtag |
| **三級**（長尾詞） | PER 99 分位 · 收益平準金 | Caption 內文 · ALT text |

## 關鍵字禁區

- ❌ 塞太多（Caption > 30% 是關鍵字）
- ❌ 用政治敏感詞（例：「習近平」「兩岸」）
- ❌ 用個股喊漲跌詞（「XX 必漲」「XX 崩盤」）

# Part 4 · 每季 SEO 稽核 SOP · 8 步驟

**每年 2 月 · 5 月 · 8 月 · 11 月執行**

### Step 1 · Profile SEO 檢查（10 min）
- [ ] Bio 3 行是否還對應本季主打
- [ ] 精選限動有沒有停滯 3 個月
- [ ] Linktree 5 個連結有沒有壞

### Step 2 · 過去一季 Caption 關鍵字覆蓋率（20 min）
- 抓 13 集 caption
- 統計出現最多的 20 個關鍵字
- 對照 Prompt 03 100 機會池的關鍵字
- **有沒有主題沒被覆蓋**（那就是下季主打）

### Step 3 · Hashtag 效能分析（20 min）
- 檢查 IG 後台**觸擊來自 Hashtag 的貼文**
- 找出 Top 10 有效 Hashtag
- 找出 Bottom 10 沒觸擊的 Hashtag
- **淘汰 Bottom · 加深 Top**

### Step 4 · ALT Text 覆蓋率（10 min）
- 抓 5 篇隨機貼文
- 檢查所有圖是否都有 ALT
- 沒有的 · 補上

### Step 5 · Discoverability 分析（15 min）
- 過去一季 4 大行為訊號趨勢
- 分享率有沒有降？（→ Pinned Comment 要換變體）
- 收藏率有沒有降？（→ P7 金句要重整）
- 快速略過率有沒有升？（→ Hook 疲勞 · 換公式）

### Step 6 · External Backlink 檢查（15 min）
- Threads / Substack / GitHub 三平台的 IG 連結是否還存在
- Google Search「通無法師」前 3 頁結果
- 有沒有負面 / 錯誤資訊 → 補 SEO 蓋過

### Step 7 · 競爭者 SEO 對照（30 min）
- 打開 Prompt 04 competitor-intel 檔
- 看 5 大 KOL 的 Bio · Hashtag · 關鍵字
- **有沒有他們用你沒用的關鍵字**（值得偷師）
- **有沒有你用了但他們沒用的**（護城河強化）

### Step 8 · 更新這份 SEO 檔（20 min）
- 把本季發現寫入
- 更新 Hashtag preset 組合
- 排 3 個下季 SEO 優化行動
