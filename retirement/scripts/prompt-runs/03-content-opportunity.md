# 🕰 主題衰退檢測機制

## 衰退指標（3 選 1 觸發 = 該主題進入淘汰考慮）

- **時效衰退**：發布後 18 個月，數據 / 政策 / 商品已變
- **飽和衰退**：其他 KOL 開始大量出類似內容，觀眾看膩
- **共鳴衰退**：Personas 世代變遷（例：40-55 歲觀眾 3 年後變 43-58 歲）

## 各主題預估半衰期

| 主題類型 | 半衰期 | 何時該更新 |
|---|---|---|
| **殺基金 X 光片個案** | 12-18 個月 | 商品下架 / 條款改變 |
| **PER 分位個股分析** | 6-12 個月 | 需重跑 rolling window |
| **技術分析批判** | **永久有效** | 只需補新數據 |
| **心理學 / 元認知** | **永久有效** | 藥師 · 邵雍不會過期 |
| **保單 / 稅務拆解** | 24-36 個月 | 法規改變 |
| **時事借勢**（AI / 央行）| 3-6 個月 | 熱點過就要下架 |
| **個人揭露 / 自傳型** | **永久有效** | 主編故事只會加深 |

## 淘汰 SOP

1. 每季 Meta Review 檢視「發布 > 18 個月」的集
2. 標記 3 種狀態：**保留** · **更新重發** · **下架**
3. 更新重發的：改標題「（更新版）」+ 印章加「重審」字
4. 下架的：Vaulted 但不刪除，寫「這集已被 Kill Condition 打臉，見 EP.XX」
