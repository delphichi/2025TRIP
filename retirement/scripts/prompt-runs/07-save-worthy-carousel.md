# Part 0 · 為什麼是輪播（vs Reel · vs 單圖）

## 3 種格式的定位分工

| 格式 | 主要 KPI | 平均停留 | 適合 |
|---|---|---|---|
| **Reel** | 完播率 · 觸擊 | 15-30 秒 | 拓新（陌生人） |
| **輪播 10 頁** | **收藏率** · 平均看到第幾頁 | 60-120 秒 | **講透** · 建信任 |
| **單圖** | 分享率 | 3-8 秒 | 破圈 · 引流回輪播 |

## 輪播是頻道**主戰場**的理由

1. **收藏率最高** —— 演算法 2026 最看重的訊號
2. **平均停留最長** —— 觀眾看完 10 頁 = 給你 60 秒信任時間
3. **可搜尋性最強** —— 每頁都可以塞關鍵字
4. **長尾流量** —— 3-14 天穩定推薦（Reel 24-72 小時就冷）
5. **知識密度最高** —— **10 頁可獨立成立的知識卡片** = 觀眾未來會回查

**核心真理**：**輪播是通無法師的靈魂載體**，Reel 只是招牌，單圖只是提醒。

## Slide-by-Slide 完整規格

### Slide 1 · Hook（Stop the scroll）

**主任務**：讓觀眾**手指停下**
**Cialdini 對應**：**Curiosity Gap（好奇心缺口）**
**Kahneman 對應**：**System 1 觸發**（直覺反應）
**字數上限**：**主標 ≤ 12 字 · 副標 ≤ 20 字**
**字級**：主標 clamp(3.4rem, 11.5vw, 8.2rem) 900 weight · 副標 1.35rem
**顏色**：主標深板岩 `#1A2130` · 重點紅 `#A83C2C`
**必備元素**：
- Eyebrow：`S0X E0Y · 藥師第 X 願 / 第 X 橫`
- Kicker：藥師偈子 · 灰塵覆蓋，本自清淨（or 對應偈子）
- Ledger 兩行：一個對照數字
- 印章：通無法師 · [本集精神字]
- SWIPE →

**內容範例（EP.01）**：
```
S01E01 · 第五願 · 恢復清淨
灰塵覆蓋，本自清淨 ——

台積電漲 3 倍。
我沒賺到錢。

[台積電這 5 年 · +308%]
[我實際賺到的錢 · 0 元]
```

**Kill Condition**：3 秒內縮圖看不清主標 → 廢

### Slide 2 · The Problem（Create curiosity）

**主任務**：**放大痛點**，讓觀眾覺得「這就是我」
**Cialdini 對應**：**Consistency（一致性）**—— 讓觀眾點頭同意問題存在
**Kahneman 對應**：**Loss Aversion（損失趨避）**
**字數上限**：**80 字內**
**字級**：主標 2.4rem · 內文 1.35rem

**必備結構**：
- **上週 / 一般人做的事**（引述）
- **這件事為什麼看起來合理**（讓讀者共鳴）
- **但⋯**（懸念）

**內容範例（EP.01 P2）**：
```
上週我說的話：
「台積電 PER 31，20 年最貴，別加碼。」

邏輯：用 20 年歷史分位判斷貴或便宜。
貴就等回檔。

聽起來很合理，對吧？
```

**Kill Condition**：讀完不會想滑下一頁 → 弱句多，需重寫

**Kahneman 對應**：**Anchoring（錨定）**—— 給讀者一個心智錨
**字數上限**：**60 字內**
**字級**：主標 2.4rem · 內文 1.35rem

**必備結構**：

- 短懸念句收尾

**內容範例（EP.01 P3）**：

### Slide 4 · Solution Overview（Deliver value）

**主任務**：**給答案骨架** —— 觀眾第一次感覺「我學到東西」
**Cialdini 對應**：**Reciprocity（互惠）**—— 我先給你價值
**Kahneman 對應**：**Peak-End Rule 起點**
**字數上限**：**主標 12 字 · 內文 80 字**
**字級**：主標 3rem · 內文 1.35rem
**視覺重點**：**大字數字 or 對照表**

**必備結構**：
- 一句結論式 punch line
- 3 條或 3 欄 對照（讓觀眾立刻抄）

**內容範例（EP.01 P5）**：
```

我上週建議的方法 → 21.51%

─────
```

# Part 3 · 輪播開頭 10 種 Hook 公式

## 公式 1 · 反直覺 punch
```
「無腦贏了聰明。」
「等便宜的人踏空 300%。」
```

## 公式 2 · 具體數字 shock
```
「台積電漲 3 倍，我 0 元。」
「20 年 CAGR 排行，第一名是⋯」
```

## 公式 3 · 損失趨避
```
「業務沒告訴你的三個字，讓你多賠 33%。」
「這樣算，一年少賺 15 萬。」
```

## 公式 4 · 好奇缺口
```
「大戶都在做的一件事⋯」
「藥師佛第 X 願告訴我一件事⋯」
```

## 公式 5 · 認錯直球
```
「我上週說錯了。」
「我沒賺到錢。」
```

## 公式 6 · 反問開場
```
「你聽過『XX 只會漲』對吧？」
「你相信『20 年歷史證明』嗎？」
```

## 公式 7 · 身分認同
```
「40+ 中年，你手上有這 5 支保單嗎？」
「退休金 300 萬的人都在算這件事。」
```

## 公式 8 · 對比放大
```
「純 DCA 23% vs 我聰明策略 21.5%。」
「無腦 vs 聰明，差 15 萬。」
```

## 公式 9 · 教典引用
```
「藥師佛第五願：本自清淨。」
「邵雍說：無我則無妄。」
```

## 公式 10 · 意外性 twist
```
「巴菲特買了台積電又賣。」
「熬夜盯盤讓我輸給睡覺的人。」
```

## Hook 疊加規則（見 Prompt 05 精神）

**一次最多疊 2 個公式** · **推薦「具體數字 + 情緒」黃金組合**

例：**「台積電漲 3 倍，我 0 元。」** = 公式 2（數字）+ 公式 5（認錯）

# Part 4 · 字數上限 + 字級標準

## 每頁字數硬性上限

| Slide | 主標字數 | 副標 / 內文字數 | 說明 |
|---|---|---|---|
| S1 Hook | **≤ 12** | ≤ 20 | 縮圖必讀 |
| S2 Problem | ≤ 20 | ≤ 80 | 留白建立節奏 |
| S3 Why | ≤ 15 | ≤ 60 | 短懸念 |
| S4 Solution | ≤ 12 | ≤ 80 | 對照表為主 |
| S5-6 Steps | ≤ 15 | ≤ 60 | 具體動作 |
| S7 Takeaways | ≤ 15/條 × 3 | — | 3 條金句 |
| S8 藥師偈子 | ≤ 15 | ≤ 40 | 極簡留白 |
| S9 CTA | ≤ 15 | ≤ 80 | 3 層 CTA |

## 字級標準（HTML template）

```css
--main-title:  clamp(3.4rem, 11.5vw, 8.2rem)  /* 主標 · 9 分之 5 頁面 */
--sub-title:   2.4rem 900 weight              /* 中標 */
--body-text:   1.35rem 500 weight             /* 內文 */
--label:       1.1rem 600 weight              /* 眉標 / 頁碼 */
--ledger-num:  3.1rem 900 weight tabular-nums /* Ledger 大數字 */
```

## 為什麼字數要限制

- **270×270 縮圖 = 觀眾第一眼**（超過 15 字就模糊）
- **短句 = 節奏 = 完播**（長句讓人跳頁）
- **留白 = 質感**（塞滿 = 焦慮）

# Part 6 · Cialdini + Kahneman 說服原則對照

## 6 大 Cialdini 原則 · 每頁對應

| 原則 | 意義 | 用在哪頁 |
|---|---|---|
| **Reciprocity（互惠）** | 我先給你價值 | S4 Solution |
| **Commitment（承諾）** | 讓讀者小承諾 | S5 · S6 Steps |
| **Social Proof（社會認同）** | 引用他人選擇 | S9 CTA |
| **Authority（權威）** | 引用教典 · 數據 | S3 Why · S8 藥師偈 |
| **Liking（喜好）** | 溫度 · 情緒 | S8 藥師偈 |
| **Scarcity（稀缺）** | 錯過感 | S9 CTA（下集預告） |

## Kahneman 認知偏誤 · 每頁對應

| 偏誤 | 用在哪頁 |
|---|---|
| **System 1** 直覺觸發 | S1 Hook |
| **Loss Aversion** 損失趨避 | S2 Problem |
| **Anchoring** 錨定 | S3 Why · S4 Solution |
| **Availability Heuristic** 可得性 | S5-S7（具體易記） |
| **Peak-End Rule** 峰終定律 | S1 起點 · S9 終點 |

**用法**：**寫每頁前先想「這頁要打哪一個心理原則」**，寫完檢查是否命中。
