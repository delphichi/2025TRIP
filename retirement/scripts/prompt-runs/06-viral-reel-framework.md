# Part 0 · Reel 拍攝 SOP（無臉 / 無配音 / 無剪輯）

## 器材（總花費 < 2000 台幣）

- **裝置**：iPhone / Android（已有）
- **腳架**：手機腳架 · 200-500 元
- **背景**：白牆 / 木桌 / 書架前（不用背景布）
- **軟體**：**只用 IG 內建剪輯**（不用 CapCut / Premiere）
- **配樂**：IG 音樂庫 · lo-fi / 純弦樂 / 環境音
- **字體**：IG 內建（PingFang · SF Pro · 系統字）

**為什麼極簡**：
- **降低疲勞** = 每週能持續產出的關鍵
- **易複製** = 未來團隊介入不需要學複雜工具
- **有辨識度** = 極簡本身就是頻道視覺 signature

## 拍攝原則 · 5 條鐵律

1. **從不露臉** — 一露臉就變個人品牌 · 頻道是**道場**
2. **從不配音** — 完全用螢幕文字 + BGM · 觀眾自己讀
3. **從不用轉場特效** — 只用「淡入淡出」和「文字上推」
4. **鏡頭 90% 是**：手拿計算機 / 桌面試算表 / 手寫筆記 / 書本翻頁 / 黑板寫字
5. **每支 Reel 只用 1 種鏡頭類型** — 保持節奏感

## 拍攝素材庫（提前拍好、重複用）

**一次性拍完，重複配文**：

| 素材類型 | 拍法 | 用在 |
|---|---|---|
| **計算機打字** | 俯拍手指按計算機（15-30 秒 · 各種角度）| 「算過」型 |
| **翻頁 / 寫字** | 俯拍手寫筆記 · 慢動作翻頁 | 「認錯」型 |
| **Excel 打字** | 錄螢幕（Screen Recording） | 「拆完」型 |
| **手翻藥師經 / 邵雍書** | 慢動作翻書 · 光影自然 | 「心法」型 |
| **窗外光影 / 茶杯** | 環境空鏡（配 kicker 用）| 過場 · 開頭 |

**建議**：**開播前先花 2 hr 拍 20 段素材** → 未來 3 個月的 Reel 都靠這 20 段配文，不用每次重拍。

## 剪輯 SOP · 只用 IG 內建（每支 20 分鐘完成）

1. **上傳 3-5 段素材**（從素材庫挑）
2. **每段 3-5 秒**（不切太快 · 不切太慢）
3. **配 BGM**（IG 音樂庫選 lo-fi · 30-45 dB）
4. **加螢幕字**（一屏一句 · 上推淡入）
5. **配色**：字色白 · 邊框深灰 · 關鍵詞紅字（配合頻道 palette）
6. **右上角** logo 貼 `@back2void`（一直顯示）
7. **檢查** 前 3 秒是否有 Hook · 最後 3 秒是否有 CTA
8. **發布**

**每支 Reel 總時間**：
- 有腳本 + 素材 · 剪輯 = **20 min**
- 加寫腳本 = **1-1.5 hr**

# Part 5 · Reel 產出 SOP + 批量法

## 一次拍 4-6 支的批量法（每月一次 · 週六早上 3 hr）

**Step 1**（30 min）：從 Prompt 03 100 機會池挑 4-6 個 Reel 主題
**Step 2**（30 min）：每個套框架決策樹 · 定 F1-F8 or EF1-3
**Step 3**（60 min）：一次寫完 4-6 個腳本
**Step 4**（60 min）：拍新素材（若素材庫不夠）
**Step 5**（30 min）：一次剪輯（每支 5 min · 用 IG 內建）
**Step 6**（30 min）：一次排程（每週一支 · 隔週三 12:00）

**產出**：**4-6 支 Reel = 未來 4-6 週不用煩惱**

**批量法的關鍵**：**同一個 flow state 產出多支**，比零星拍效率高 3-5 倍。
