# 退休規劃 & 反焦慮財經頻道

> **定位**：用數據拆穿財經廣告、破解訂閱訊號、幫觀眾少虧錢少焦慮
> **語言**：繁體中文為主，可雙語
> **格式**：YouTube 8-12 分鐘長片 + Threads/Shorts 3-5 分鐘短片
> **時間**：下班/週末製作，一週目標 1 支長片 + 2 支短片

## 各資料夾用法

### `conversations/`
每次跟 AI（Claude / ChatGPT）或朋友深度討論後，把技術摘要放這裡。**這是影片內容最原始的素材庫**。

**檔名慣例**：`YYYY-MM-DD-主題.md`

**現有**：
- `2026-08-06-conversation-summary.md` — 從 AlphaPicks 因子分析到 3 年退休計畫（涵蓋 backtest、行為財務、台灣 ETF、稅務、既有資產體檢）

### `scripts/`
每支影片一個資料夾：
```
scripts/
└── EP001-alphapicks-alpha-check/
    ├── outline.md         ← 大綱、要點
    ├── script.md          ← 逐字稿
    ├── data.md            ← 引用數據 / 表格
    ├── kill-conditions.md ← 「這集若被推翻怎麼認錯」
    └── thumbnail.png      ← 縮圖草稿
```

**檔名慣例**：`EPNNN-短標題-slug`

### `research/`
資料分析、backtest、Python 腳本、圖表產出。

**檔名慣例**：`YYYY-MM-DD-主題.py` 或 `.md`

### `notes/`
靈感、觀察、待驗證假設、下期選題候選。

**檔名慣例**：自由

### `assets/`
圖表、縮圖、圖示、示意圖。

## 頻道核心原則

### ✅ 該做
1. **有數據支撐**——每個結論都能用數字或迴歸驗證
2. **承認不確定性**——「t=0.99 不能拒絕虛無假設」比「這是黃金訊號」誠實
3. **公開對帳**——舊影片預測若錯，回頭認錯
4. **每集寫 kill condition**——「若 XX 情況發生，我承認錯」
5. **針對話術，不針對人**——「這類主張」而非「XX 老師說的」

### ❌ 不該做
1. ❌ 開課、賣訂閱、開群（會諷刺自己的定位）
2. ❌ 接業配（證券商、財管、投顧）
3. ❌ 做「今日盤勢」（sensational 陷阱）
4. ❌ 指名攻擊特定 KOL（法律風險）
5. ❌ 每天發（會累到放棄）

## 影片製作工作流

### 一支影片的生命週期
1. **選題**（notes/ 或 conversations/ 挖靈感）
2. **開新資料夾**（`scripts/EPNNN-slug/`）
3. **寫 outline.md**（3-5 個要點 + 每點的數據支撐）
4. **寫 script.md**（8-12 分鐘 ≈ 1,500-2,000 字）
5. **寫 kill-conditions.md**（未來若被推翻的判準）
6. **產出 data.md**（表格、圖表引用）
7. **錄製 + 剪輯**（OBS + CapCut / DaVinci Resolve）
8. **縮圖**（Canva，套用一致模板）
9. **上片 + 每季對帳**

### 每季自檢
- [ ] 我的舊預測對了幾成？
- [ ] 觀看時長最長的類型是哪類？
- [ ] 留言區反覆問的問題是什麼？（→ 下期選題）
- [ ] 我有沒有變成我批判的對象？

## 一個 counter-intuitive 提醒

**別以「幫大家賺錢」為目標**——這會逼你變成訊號商，失去可信度。

**目標是「幫大家少虧錢、少焦慮」**——這是**永遠可以說真話**的定位。

**巴菲特一輩子公開內容都是「少虧錢」定位**，不是「教你賺錢」。
