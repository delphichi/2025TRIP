# 通無 · Dilts 邏輯層次身份定義

> 建檔：2026-08-10
> 定位：**頻道 6 層身份系統** · 上層引導下層 · 全對齊才不會爆炸
> 觸發：從「通無法師（度眾生）」→「通無（紀錄自我反思）」的深度校準

---

## Dilts 6 層 · 從上到下（上層決定下層）

```
┌──────────────────────────────┐
│  使命  Purpose · 為誰？        │  ← 頻道存在的最終理由
├──────────────────────────────┤
│  身份  Identity · 我是誰？      │  ← 主編扮演的角色
├──────────────────────────────┤
│  價值觀 Values · 為什麼？      │  ← 判斷對錯的依據
├──────────────────────────────┤
│  能力  Capability · 如何？     │  ← 讓行為可能的技能
├──────────────────────────────┤
│  行為  Behavior · 做什麼？     │  ← 觀察得到的動作
├──────────────────────────────┤
│  環境  Environment · 何時何地？│  ← 發生的時空條件
└──────────────────────────────┘
```

**核心原則**：**問題如果出在下層，解方一定在上一層**。
- 行為出問題（發不出文） → 是能力不夠 or 價值觀動搖
- 能力出問題（不會寫回測） → 是價值觀決定「值不值得學」
- 價值觀出問題（想接業配） → 是身份錯位（我不是修行者 · 是 KOL）
- 身份出問題（想當老師）→ 是使命錯位（度眾生 vs 自度）

# 使命 · Mission · 這頻道存在是為了什麼

## 定義

> **紀錄一個 40+ 中年男 · 在金融焦慮的時代 · 練習「通無」的過程。**
> **順帶讓有緣人看到 —— 原來可以這樣活。**

## 3 層深度

### 表層：內容產出
每週發 1-2 篇紀錄「我這週怎麼練習不執著」

### 中層：3 年後退休的見證
2029 年退休那天 · 這個頻道是**修行的公開檔案** · 證明「我沒有白過這 3 年」

### 深層：金剛經的實踐
**「應無所住而生其心」** —— 認真做，但不執著做的結果。
連「這個頻道要成功」都不執著。

## 使命的 Kill Condition

**如果哪天我開始想「我要度多少人」「我要有多少追蹤」「我要幫多少人破解焦慮」**
→ 使命已錯位 → 停 3 天 · 讀金剛經 · 回到「這是我自己的修行紀錄」

# 身份 · Identity · 我是誰

## 定義

> **「通無」= 一個正在練習消解執著的中年男。**
>
> **不是**「通無法師」（因為「法師」預設了「有法可傳給眾生」的相）。
> **是**「通無」—— 動作本身、路徑本身、還沒完成的過程本身。

## 我不是什麼（同樣重要）

| ❌ 我不是 | ⚠️ 為什麼要避免 |
|---|---|
| 法師 · 老師 · 顧問 · 專家 | 這些角色預設「我在上、你在下」 |
| KOL · 網紅 · 影響力人物 | 這些預設「我的目的是被看見」 |
| 財經作家 · 分析師 · 部落客 | 這些預設「我在生產內容給你消費」 |
| 反話術鬥士 · 消費者保護者 | 這些預設「我在對抗某某」（有敵） |
| 智者 · 修行有成之人 | 這些預設「我已到達 · 你還沒」 |

## 我是什麼

| ✅ 我是 | 因為 |
|---|---|
| **一個記錄者** | 我在寫日記 · 有人在旁邊看是額外的 |
| **一個同修** | 我還在路上 · 你也在路上 |
| **一個算過帳的人** | 我用計算機、不用預言 |
| **一個承認會錯的人** | 每篇有 Kill Condition |
| **一個正在戒斷貪瞋癡的人** | 這是每天的功課 · 不是完成式 |

## 身份的 Kill Condition

**如果哪天有人稱我「老師 / 大師 / 法師」我覺得舒服 · 沒有不自在**
→ 身份已錯位 → 立刻公開澄清「我不是老師 · 我是記錄者」

# 價值觀 · Values · 為什麼這樣做

## 核心信念 · 5 條

### 1. 誠實比正確重要
- 錯了就承認 · 不護錯 · 不留面子
- Kill Condition = 這個信念的紀律化

### 2. 承認錯是最強的護城河
- 每次認錯 · 觀眾信任 +1
- 每次護錯 · 觀眾信任 -10
- 這個不對稱 · 決定頻道 3 年後有沒有觀眾

### 3. 不預測 · 不明牌 · 不個股喊進出
- 因為「凡所有相皆是虛妄」 · 未來預測都是妄相
- 因為「眾生非眾生」 · 個股背後是活人的執念 · 不該喊

### 4. 不變現 · 不業配 · 不賣課
- 不是道德潔癖 · 是自我保護
- 一收錢 · 就有必須說某些話的壓力 · 修行就斷了
- 3 年後退休 · 這頻道是社會信任資產 · 不是收入來源

### 5. 觀眾是同修 · 不是學生
- 我沒有要教什麼 · 我只是把日記公開
- 你要來看 · 歡迎 · 你要走 · 也歡迎
- 你懂了什麼 · 是你的功勞 · 不是我的

## 價值觀的 Kill Condition

**如果哪天我在寫作時想「這樣寫觀眾會怎麼看我」**
→ 價值觀已錯位（在意「相」了） → 刪掉重寫

# 6 層對齊檢查 · 3 秒 self-check

**每天早上開 IG 前 · 問自己 6 題**：

```
1. 使命：我今天的動作是為了記錄自己，還是為了度別人？
2. 身份：我今天是修行者，還是想當老師？
3. 價值觀：我今天有沒有在為某個「相」（讚 · 追蹤 · 收藏）動搖？
4. 能力：我今天的能力足以支撐我要做的事嗎？
5. 行為：我今天的動作跟我的價值觀對齊嗎？
6. 環境：今天的環境跟我原本設定的一樣嗎？如果不一樣，我要怎麼調？
```

**任一題答案模糊 → 停 · 讀 MANIFESTO 4 句 + 三重覺知偈 → 想清楚再動。**
