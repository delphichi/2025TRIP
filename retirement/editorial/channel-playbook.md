# 破解焦慮財經頻道 · 內容套用手冊

把 ericchi 的 IG 框架，翻譯成**本頻道專屬**的執行守則。

---

## 一、頻道定位（永遠先寫在最上面）

- **利基**：40-55 歲、有點錢但被金融產品搞混、看新聞會焦慮的台灣人
- **承諾**：用計算機和數據，把「銷售話術」還原成「數學真相」
- **反差**：市面上「教你賺錢」的一堆，本頻道**教你不要被騙**
- **禁區**：不推薦個股、不預測未來、不喊進出、不業配保險基金

## 四、每集必過的 5 關檢核（發布前貼在打稿旁邊）

### 【主題檢核】
- [ ] 這集**只講一件事**？（不是「殺基金三部曲」，是「殺基金第 X 種：AUD 特別股」）
- [ ] 對特定人有用？（40-55 歲、手上有 100 萬～500 萬台幣可投資）

### 【標題檢核】
- [ ] 結果寫法 + 至少 2 元素（對象／痛點／明確結果）
- [ ] 疊 2 個 Hook 公式（不要 3 個以上）
- [ ] 15 字內
- [ ] **縮圖 270×270 還讀得懂**

### 【內容檢核】
- [ ] 每個結論都有**可驗證的數據**（絕不引用二手結論）
- [ ] 至少一個**反直覺的發現**（不然沒必要看）
- [ ] 有 **Kill Condition**：「如果 X 發生，我的結論就錯了」
- [ ] 沒有推銷任何金融商品
- [ ] 沒有預測未來股價

### 【視覺檢核】
- [ ] 一頁一個焦點（不要塞滿）
- [ ] 主標大到滑過去都看得懂
- [ ] 拿掉標題，圖還能猜到主題

### 【品牌檢核】
- [ ] 不像在教人（像一個算過帳的朋友在跟你講）
- [ ] 不炫耀（沒有「我當年怎樣賺了 XX」）
- [ ] 有個人風格（承認自己也曾追高殺低）

## 六、週度製作節奏（給自己抓時間用）

```
週一晚：從素材倉庫挑一個主題，跑或補回測數據（research/）
週三晚：套框架寫輪播 8-10 頁草稿（scripts/）
週五晚：排版、錄音、剪輯
週日：發布 + 追蹤前 4 小時停留/收藏/分享數據
```

**永遠不看**：按讚數（IG 演算法已經不看，我們也不看）
**核心 KPI**：收藏數（專業信任訊號）+ 分享數（觀眾覺得對別人有用）

---

## 七、Kill Condition（何時該重新檢視這套 playbook）

- 連續 5 支內容收藏數 < 30 → 主題選錯（回頭改利基）
- 連續 5 支分享數 < 10 → 內容沒觀點（加強反直覺洞察）
- 3 個月粉絲數 < +100 → 拓新內容太少（拉高 Reels 比例）
- 業配邀約出現 → **拒絕**（一旦收錢就失去頻道核心）
