# 一集內容製作 SOP · 從素材到封面的完整流程

> 這是 EP.01「我被數據打臉」的實際製作過程紀錄，抽象成可重複的 7 步驟 SOP。
> 之後每一集都照這個走，不用重新想流程。
> **總耗時參考**：EP.01 從素材到定稿 ≈ 6-8 小時（分散在一週）。熟練後可壓到 3-4 小時。

---

## 前置：三份必讀

每次開新集之前，先花 5 分鐘掃過這三份，把腦袋校準：

1. [`channel-playbook.md`](./channel-playbook.md) —— 頻道定位、目標觀眾、禁區、素材倉庫
2. [`ericchi-ig-masterclass.md`](./ericchi-ig-masterclass.md) —— 5 個 Prompt 的原始定義、Hook 9 公式、封面 5 關
3. [`../scripts/episode-01/cover.md`](../scripts/episode-01/cover.md) —— 頻道視覺系統（palette / 印章 / 帳本橫線）

---

## Step 0 · 選素材（15 分鐘）

打開 [`channel-playbook.md`](./channel-playbook.md) 的**素材倉庫**，挑一個 ⭐⭐⭐ 或 ⭐⭐ 的主題。

**選擇 checklist**：
- [ ] 這個主題**只講一件事**（不是三部曲，是「AUD 特別股殺基金」單一目標）
- [ ] 對特定人有用（40-55 歲、手上 100-500 萬）
- [ ] 有**數據可支撐**（已在 `research/` 跑過，或這集就會跑）
- [ ] 至少有**一個反直覺的發現**（不然沒必要看）
- [ ] 沒踩禁區（不推銷、不預測、不個股喊進出）

**EP.01 的選擇**：從倉庫挑「20 年歷史抓台積電踏空 5 年」（⭐⭐⭐）。
理由：稀缺（沒人敢自我打臉）+ 話題性強（2330 全民股）+ 定位效果最強（開台一擊定調）。

---

## Step 1 · 跑 Prompt 1（策略層）· 15 分鐘

**目的**：不是為這集想 10 個標題，是把「這集屬於一個更大的內容宇宙」思考清楚，避免主題撞車。

**輸入 Claude 的三個變數**：

```
Niche    = 台灣個人理財（破解殺基金、業務話術、財經焦慮）
Audience = 40-55 歲、手上 100-500 萬、被理專/保險/YouTuber 搞混的上班族
Goal     = 建立「用數據拆解」的專業信任，讓觀眾學會自己算
```

貼上 [`ericchi-ig-masterclass.md`](./ericchi-ig-masterclass.md) 裡的 Prompt 1 全文，跑出：
- 目前市場 **7 個最飽和**的內容模式（要主動避開）
- **10 個打破模式**的原創貼文創意
- 每個創意含 5 個欄位（核心 / Hook / 格式 / 新鮮點 / 收藏邏輯）
- **前 3 名排名 + 理由**

**產出範例**：見 EP.01 對話中的「Prompt 1 執行結果」段落。

**這一步的價值**：即使這集只做第一名，你也知道另外 9 個是**下一季的內容池**。素材倉庫會自動累積。

---

## Step 2 · 跑 Prompt 2（Hook 層）· 15 分鐘

**目的**：為選定的創意寫 15 個 Hook。**這一步是全集最重要的一步** —— 觀眾 0.8 秒決定滑不滑。

貼上 Prompt 2 全文 + 三個變數：
```
Idea     = 你在 Step 1 選定的第一名創意
Audience = 同上
Tone     = 算過帳、承認會錯、口語但精準、不推銷
```

產出 5 種類型 × 3 個 = 15 個 Hook：
- 好奇心型 · 反向思考型 · 情緒張力型 · 具體數字型 · 低調權威型

**Hook 品管規則**（Claude 產完自己過一遍）：
- [ ] 長度 ≤ 15 字
- [ ] **零標題黨、零誇張承諾**
- [ ] 讀起來像真人（不是「震撼揭密！5 個秘密⋯」）
- [ ] 有具體數字或情境，不空泛

**選 Top 5**：從 15 個裡挑 5 個進下一階段。**優先挑「數字 + 情緒」混合型**（Prompt 4 的黃金組合）。

**EP.01 選的 5 個**：
1. 我被數據打臉，台積電漲 3 倍，我 0 股
2. 「等便宜」害我錯失 300% 漲幅
3. 眼睜睜看它從 591 漲到 2370
4. 純 DCA 完勝我的「聰明策略」
5. 歷史分位法，該退休了

---

## Step 3 · 跑 Prompt 3（格式層）· 30 分鐘

**目的**：把 1 個創意 × 5 個 Hook 轉成**3 種無臉格式**（輪播 / Reel / 單圖）。

貼上 Prompt 3 + 交出 Step 2 的 5 個 Hook，讓 Claude 分配：
- **輪播**：適合長 Hook（Hook 1 這種混合式），10 頁架構
- **Reel**：適合短 + 情緒 Hook（Hook 3 這種畫面感）
- **單圖**：適合對照 Hook（Hook 4「A vs B」結構）

**每個版本 Claude 必須提供 5 欄**：
1. 完整內容結構（每頁 / 每幕在說什麼）
2. 螢幕上的文字（逐字稿）
3. 視覺方向（背景 / 字型 / 顏色）
4. 說明文案（Caption）
5. CTA

**限制強制執行**：不露臉 · 不配音 · 不跟風 · 不需複雜剪輯

**EP.01 產出**：見 `scripts.md`（Prompt 4 優化後的最終版）。

---

## Step 4 · 跑 Prompt 4（留存優化）· 20 分鐘

**目的**：把 Step 3 的輪播 10 頁逐頁精修，最大化 4 個 KPI：觀看時長 / 完播率 / 收藏 / 分享。

**7 個核心技巧**（每頁改的時候檢查）：

| 技巧 | 說明 | 範例 |
|---|---|---|
| **Bucket Brigade** | 每行結尾要拉下一行 | 「聽起來很合理，對吧？」→ 逼下頁 |
| **刪弱句填充詞** | 「其實」「基本上」「你知道嗎」全砍 | 「這方法有效」而非「這個方法基本上是有效的」 |
| **Punchline First** | 結論放前面，細節放後面 | P5 開場直接「無腦贏了聰明」 |
| **抽象變具體** | 「賺很多」→「5 年少賺 15 萬」 | 觀眾能算自己 |
| **CTA 融進內容** | 不硬推「請收藏」，給觀眾**內化工具** | 「你腦中要有一個聲音」 |
| **分享對象點名** | 不只「請分享」，指出**傳給誰** | 「分享給還在等回檔的朋友」 |
| **Kill Condition** | P9 固定給觀眾一個「何時該罵我」的條件 | 「PER 12 個月沒回中位，我承認又錯」 |

**改完後 Claude 必須條列說明**：改了什麼、為什麼這樣更好。這是**元認知學習** —— 你會越改越懂。

---

## Step 5 · 跑 Prompt 5（品牌語氣層）· 20 分鐘

**目的**：把 Step 4 的定稿改寫成 3 種語氣，適用不同場合。

貼上 Prompt 5，Claude 產出：
- **優雅版**：有質感、有留白 → 週日深度輪播、深度粉絲信
- **直接版**：短句、快節奏 → Reels 字幕、通勤 timeline
- **高端感版**：精準用字、低調有份量 → LinkedIn / Threads 專業圈

**品管**：
- [ ] 不像在教人（沒有「你要」「你應該」）
- [ ] 不炫耀數字或成就
- [ ] 不高高在上
- [ ] 讀起來像**真正懂的人在說真話**

**實務用法**：主要用**直接版**在 IG，**高端感版**同步發到 Threads / LinkedIn 破圈到專業圈。優雅版留給重要節點（月結、季結、大轉折）。

---

## Step 6 · 做封面（首集 90 分鐘，後續每集 15-30 分鐘）

### 首集要做的事（一次投資，長期回本）

1. 打開 [`../scripts/episode-01/cover.md`](../scripts/episode-01/cover.md) 看 palette 定義
2. 打開 [`../scripts/episode-01/cover-p1.html`](../scripts/episode-01/cover-p1.html) 當 template
3. 用 Chrome DevTools 截圖成 PNG

### 每一集要換的三個地方

| 元素 | 每集調整 |
|---|---|
| **主標** | 換成該集 Hook 第 1 名 |
| **Ledger 兩行** | 換成該集最核心的兩個數字對照 |
| **印章第二字** | 換成該集精神（認錯 / 拆完 / 證偽 / 對帳 / 補丁 / 結案） |

### 每一集**不要動**的東西

- Palette（煙燻藍灰 + 深磚紅）
- 字型（PingFang TC 900）
- 帳本橫線紋理
- 5 段格結構
- 印章位置 + 傾斜角度
- Footer 帳號 handle

**理由**：這些是頻道的**視覺指紋**。動了就不像同一頻道的內容。

### 常見錯誤（EP.01 iteration 學到的）

- ❌ 用奶油底 → AI 味重
- ❌ 紅色字下面畫紅色劃線 → 不清楚
- ❌ 加太多視覺元素、圖示、插畫 → 破壞冷靜感
- ❌ 印章第二字每集都一樣（例：都寫「認錯」）→ 沒有變化，記憶點消失。第一字固定「通無法師」，第二字每集換（認錯 / 拆完 / 證偽 / 對帳）

## Step 7 · 存檔 + 發布（30 分鐘）

### 建立資料夾

```bash
mkdir retirement/scripts/episode-0X
```

### 必備 4 檔（照 EP.01 結構）

```
episode-0X/
├── README.md            # 主題 · KPI · Kill Condition · 發布時程
├── scripts.md           # Prompt 4 優化版三格式文案
├── voice-variants.md    # Prompt 5 三個語氣版本
├── cover.md             # 這集的印章文字選擇 + 有沒有 iteration
└── cover-pX.html        # 封面原始檔（複製 EP.01 template 改主標）
```

### Commit + Push

```bash
git add retirement/scripts/episode-0X/
git commit -m "retirement/scripts/episode-0X: [主題名]"
git push
```

### 發布順序（一週三發，一個主題多次利用）

- 週日 20:00 → 單圖版 (Explore 破圈)
- 週一 20:00 → 輪播版 (深化 + 收藏)
- 週三 12:00 → Reel 版 (第二波觸擊)
- Threads / LinkedIn → 高端感版同步發

## 錯誤預防清單（Kill Condition for the Process）

**這集不要發**，如果符合任一條：

- [ ] 我沒有**具體數據**支撐主要論點（只是「感覺」）
- [ ] 我在**推薦具體個股買賣**（頻道核心禁區）
- [ ] Hook 需要**誇張才有力**（表示內容本身不夠強）
- [ ] Kill Condition 我**想不出來**（表示自己不知道何時該認錯）
- [ ] 過去 72 小時我情緒**波動大**（會影響 voice 的誠實度）

## 每季一次的 Meta Review

每 3 個月回頭看：
- 過去 12 集哪一集**收藏率最高**？為什麼？
- 哪一集**分享率最高**？主題有共通點嗎？
- 哪些 Hook 公式**已飽和**？（需要換新的）
- 有沒有**素材倉庫**的主題連續 6 個月沒動？（可能該淘汰）

把這些發現寫進 [`channel-playbook.md`](./channel-playbook.md) 的更新區塊。**這份 SOP 也要每季更新一次**。

---

## 最重要的一件事

**這套 SOP 不是為了讓每集都一樣**，是為了**把「決策疲勞」降到最低**，讓你把腦袋留給真正重要的事：

- 這集的**反直覺洞察**是什麼？
- 觀眾看完會**帶走什麼可以自己用的工具**？
- 3 個月後回看這集，我會不會**打自己的臉**？

SOP 解決重複性問題，讓創作力可以專注在單集的靈魂。
