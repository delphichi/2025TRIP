## 使用流程

```
1. research/ 產出財經分析（例：台積電籌碼、殺基金淨值組成、DCA 回測）
       ↓
2. editorial/ 提供框架（結果寫法、數字+情緒 Hook、5 關檢核）
       ↓
3. scripts/ 依框架寫成該集完整逐字稿 + 封面文案
       ↓
4. 錄製發佈
```

## 三個必記的規則（打稿前貼在螢幕上）

1. **結果寫法 ≠ 主題寫法** —— 「殺基金分析」→「10 年賠 30% 的基金，淨值組成藏了什麼」
2. **一次只疊 2 個 Hook 公式** —— 推薦「具體數字 + 情緒」
3. **縮圖 25% 測試** —— 主標縮到 270×270 還讀得懂才算過關
