# 七套視覺世界

每一套都是**完整的世界**：版面、字體、色彩、圖像、動效互相支撐。不是換色票而已。

## 先讀這段：怎麼用才不會變成套模板

**世界由題材決定，不是由喜好決定。** 每套下方的「什麼題材配得上」就是選用條件。
把航班看板套到婚禮邀請卡、把積木說明套到財報，會得到「看起來像那個風格但哪裡不對」的結果 ——
因為世界的說服力來自它和內容的邏輯關係，不是它的長相。

**選定後就整套committed。** 半套最糟：留著原本的卡片陣列、只換顏色，等於在兩個世界之間
和稀泥。要換就連版面骨架、字體、圖像策略一起換。

**色票是起點不是終點。** 下面每組都標了實測對比值。標示「僅限大字」的顏色不可用於正文，
這是硬限制；要當正文就用旁邊給的加深版。中文小字比拉丁文更吃對比，寧可再深一階。

**受限色盤放不下四條對等系列。** 這條是套了四套之後歸納出來的：世界 1、3、7 都在
「四條資料線」上卡住 —— 不是對比不夠，就是相鄰 ΔE 低於 15。硬擠第四個色相會同時破壞
世界的紀律和可辨識度。正解是**檢查有沒有哪一條其實不是對等系列**：基準線、參考值、
累計本金這類東西本來就是背景刻度，降格成細線即可（只需 3:1 的圖形物件對比，
不參與分離度檢查）。真的四條都對等時，這個世界就是不適合這份資料，換一個。

**先問一句再動手。** 使用者沒指定世界時，依題材推薦兩套並說明差異，讓他選。
使用者已經指定（「我要瑞士那種」）就照做，不要改推自己偏好的。

## 1. 磁磚遺產 Azulejo Heritage

> 藍白磁磚、銅版畫、鐵道懷舊。整頁近乎單色藍。

**什麼題材配得上**：有歷史縱深的實體事物 —— 鐵道、港口、老店、地方志、工藝、旅行路線。
題材必須真的有過去，否則是假古董。

| 項目 | 規格 |
|---|---|
| 版面 | 左側窄欄固定導覽（小圖示＋短標籤），右側主欄。主欄以**畫框**分區：每區用細雙線或磁磚紋外框包起來，像一片一片的磁磚拼接 |
| 首屏 | 一張橫幅的線描／銅版畫插圖佔滿寬度，標題壓在插圖下方的框內，不疊在圖上 |
| 字體 | 標題：襯線，偏 transitional／old-style，全大寫加寬字距。正文：同族襯線。**不用無襯線** |
| 色彩 | 紙 `#f4f1e8`／磁磚白 `#fbfaf6`／主墨 `#1c3f7a`（**9.11:1** ✅）／次要 `#4a6a9e`（**4.83:1** ✅） |
| 圖像 | 單色線描或銅版畫風插圖。**不用彩色照片** —— 彩照會立刻破壞磁磚的單色邏輯 |
| 細節 | 細雙線分隔、四角小裝飾、編號用羅馬數字或小型大寫 |
| 動效 | 幾乎沒有。最多淡入。這個世界的質感來自靜止 |

**禁忌**：圓角卡片陰影、漸層、emoji 圖示、彩色照片、無襯線標題。

## 2. 暗色器械 Dark Instrument

> 深色底、單一橘色強調、產品本身就是主角。硬體感。

**什麼題材配得上**：有實體或擬物介面的工具 —— 硬體、樂器、開發者工具、交易終端、測量儀器。

| 項目 | 規格 |
|---|---|
| 版面 | 首屏左文右物（或上文下物）。下半部是**規格帶**：橫向排開的小欄位，每欄一個標籤＋一個值，欄與欄之間細線分隔 |
| 首屏 | 產品以 3/4 視角、棚拍打光、深色背景上浮起。物件必須是**主角**，佔首屏一半以上 |
| 字體 | 標題：無襯線，中等字重，**全大寫加寬字距**（0.08–0.15em）。標籤與數值：等寬。正文：同族無襯線 |
| 色彩 | 底 `#101113`／面板 `#191b1e`／主字 `#e8e6e1`（**15.15:1** ✅）／次要 `#9a9ca1`（**6.88:1** ✅）／強調 `#ff6a1f`（**6.60:1** ✅） |
| 圖像 | 產品實拍或高擬真渲染。背景與頁面底色同調，讓物件像浮在頁面裡 |
| 細節 | 強調色**極度節制**：只給一個主要動作、一個狀態燈、一條資料線。其餘全灰階 |
| 動效 | 一個主動作（物件緩慢旋轉或推近），其餘靜止 |

**禁忌**：多個強調色、亮色背景區塊、手繪插圖、圓潤友善的字體。

## 3. 瑞士國際 Swiss International

> 巨大無襯線標題、紅黑雙色、嚴格網格。資訊密度高。

**什麼題材配得上**：需要被清楚理解的節目與資訊 —— 音樂廳、美術館、展覽、時刻表、年報、學術。

| 項目 | 規格 |
|---|---|
| 版面 | **嚴格多欄網格**（12 欄起跳），所有元素對齊欄線。大標題橫跨數欄，下方是密集的小字資訊塊，每塊寬度固定 |
| 首屏 | 標題字級極大（視窗寬度的 8–12%），三到四行，行距緊到接近字高。旁邊立刻是抽象幾何圖形（粗直條、色塊、條碼狀線群），**不是照片** |
| 字體 | 全站一套 grotesque 無襯線。標題極粗、字距收緊（-0.02em）。小字用同族 regular，字級小但行距寬 |
| 色彩 | 紙 `#f2f0eb`／墨 `#111111`（**16.58:1** ✅）／紅 `#d8232a`（**4.40:1** ⚠️ 僅限大字、色塊、線條）。紅色要當正文請改 `#c41f26`（**5.16:1** ✅） |
| 圖像 | 抽象幾何。色塊、直條、斜紋、條碼。攝影只在絕對必要時出現，且裁切成矩形對齊網格 |
| 細節 | 髮絲線分隔、左對齊到底、不置中、不留圓角 |
| 動效 | 無或極少。網格本身就是秩序 |

**禁忌**：置中對齊、圓角、陰影、漸層、第三個顏色、襯線字。

## 4. 資料肖像 Data Portraits

> 米色紙、紅黑芥黃、手工感的統計圖。Du Bois 式的資料新聞。

**什麼題材配得上**：有社會意義的統計 —— 人口、教育、勞動、歷史資料、調查報告。
題材要真的有資料，否則是裝飾。

| 項目 | 規格 |
|---|---|
| 版面 | 上半部一個**巨大的單一圖形**（同心圓、螺旋、放射）當作主視覺，旁邊是檔案照片。下半部是**多欄小圖卡陣列**，每張卡一個小型統計圖＋標題＋一行說明 |
| 首屏 | 標題用粗襯線或粗 slab，兩行，全大寫。主圖形是**手工感的幾何**，不是程式預設圖表 |
| 字體 | 標題：粗襯線／slab，全大寫。小字：condensed 無襯線或同族襯線小型大寫 |
| 色彩 | 紙 `#f0e6d2`／墨 `#1a1a1a`（**14.05:1** ✅）／紅 `#b2232a`（**5.35:1** ✅）／芥黃 `#d9a441`（**1.82:1** ❌ **只能當填色，永遠不可當文字**）／墨綠 `#2f6b63` |
| 圖像 | 黑白檔案照片（可加米色濾鏡融入紙色）＋ 手繪感圖表 |
| 細節 | 圖表用實心色塊，不用漸層。標籤直接寫在圖上，不用圖例 |
| 動效 | 圖形依序繪出（像被手畫出來），一次就好 |

**禁忌**：芥黃當文字色、程式預設的圖表樣式、彩色照片、圓角卡片。

## 5. 積木說明 Instruction Manual

> 飽和藍底、白色圓角卡、編號步驟、玩具實拍。友善清楚。

**什麼題材配得上**：需要照步驟完成的事 —— 組裝、教學、入門引導、設定流程、食譜。

| 項目 | 規格 |
|---|---|
| 版面 | 左側 app 式導覽，主區是**飽和色大色塊**，白色圓角卡浮在上面。核心區塊是**編號步驟列**：1→2→3→4 橫向排開，每步一張小圖＋一行字 |
| 首屏 | 左文右物。標題兩行、粗體、句首大寫（**不全大寫**）。產品實拍去背浮在色塊上 |
| 字體 | 幾何無襯線，字重對比大（標題 700、正文 400）。圓潤但不幼稚 |
| 色彩 | 主場 `#1478d4`（白字 **4.50:1** ⚠️ 大字可、正文請改 `#1169bd` **5.56:1** ✅）／卡 `#ffffff`／卡上文字 `#10233a`（**15.87:1** ✅）／零件色：黃 `#ffcc00`、紅 `#e53935`（只當物件顏色，不當文字） |
| 圖像 | 產品實拍去背，打光均勻、無戲劇陰影。每個步驟都要有對應的實物小圖 |
| 細節 | 圓角 8–12px、卡片間距一致、步驟編號用圓形或方形底 |
| 動效 | 步驟卡依序滑入一次。hover 輕微抬升 |

**禁忌**：暗色背景、襯線字、戲劇打光、抽象插圖取代實物圖。

## 6. 航班看板 Departure Board

> 純黑底、等寬字、琥珀與綠的狀態色。資訊即介面。

**什麼題材配得上**：即時或準即時的狀態資訊 —— 交通時刻、系統監控、排程、訂單狀態、市場報價。

| 項目 | 規格 |
|---|---|
| 版面 | 幾乎全部是**表格**。左側窄導覽，主區是等寬的資料列，欄位嚴格對齊。標題區也用表格的邏輯排列 |
| 首屏 | 標題用等寬字、**極寬字距**（0.2em 以上）、全大寫，斷成三短行，像翻牌顯示器 |
| 字體 | 全站等寬。標題用同一套的粗體放大。**不混搭比例字體** |
| 色彩 | 底 `#0b0d0e`／主字 `#e6e6e6`（**15.61:1** ✅）／琥珀 `#f0a500`（**9.36:1** ✅）／綠 `#35c46b`（**8.59:1** ✅）／紅 `#e5484d`（**4.98:1** ✅） |
| 圖像 | **沒有圖像**。這個世界靠排版與狀態色，不靠圖 |
| 細節 | 狀態色一律配文字標籤（`● ON TIME`），不單靠顏色。數字用 tabular-nums 對齊 |
| 動效 | 資料更新時單格翻動或閃一下，其餘不動 |

**禁忌**：任何照片、圓角、漸層、比例字體、裝飾性圖示。

## 7. 牛皮橘 Kraft Orange

> 飽和橘場域、紙箱攝影、粗壓縮大寫標題。庫存與archive感。

**什麼題材配得上**：有實體庫存與來歷的東西 —— 二手、選物、archive、倉儲、球鞋、唱片、書店。

| 項目 | 規格 |
|---|---|
| 版面 | 左側窄導覽，主區大面積單一橘色。攝影**以堆疊陣列出現**（箱子、盒子、層架），版面本身模仿貨架的格狀 |
| 首屏 | 標題粗體壓縮無襯線、全大寫、兩到三行，左對齊。右側是堆疊的實物攝影 |
| 字體 | 壓縮（condensed）粗無襯線當標題，正文用同族或中性無襯線 |
| 色彩 | 場域 `#d4601a`／橘上深字 `#1c1410`（**4.74:1** ✅）／橘上白字（**3.83:1** ⚠️ 僅限大標題）；白字要當正文請把橘加深為 `#c25415`（**4.59:1** ✅）／奶油 `#f5ead7`（**3.21:1** ⚠️ 只能大字） |
| 圖像 | 實物攝影，暖調，帶紙箱／牛皮紙質感。物件要**成堆**出現，強調數量與來歷 |
| 細節 | 標籤做成貼紙或戳印的樣子。編號、尺碼、年份這類資訊用等寬字 |

## 速查：怎麼挑

| 你的內容是 | 選 |
|---|---|
| 有歷史的實體事物 | 1 磁磚遺產 |
| 一個工具或硬體 | 2 暗色器械 |
| 需要被讀懂的節目／資訊 | 3 瑞士國際 |
| 有社會意義的統計 | 4 資料肖像 |
| 照步驟完成的流程 | 5 積木說明 |
| 即時狀態與數字 | 6 航班看板 |
| 有來歷的庫存 | 7 牛皮橘 |

同一份內容常有兩套合理。例如投資組合報表：偏「讀懂配置」選 3，偏「盯盤狀態」選 6。
拿不定就把兩套的差別講給使用者聽，讓他決定。

## 套用時一定要做的事

1. **先看現況**。既有頁面若已經有一套成立的世界，換之前要說清楚是 refinement（保留身分）
   還是 redesign（替換身分）—— 不要半套。
2. **查對比**。上面的數值是針對指定的底色算的；只要改了底色就要重算。
   中文正文一律 ≥4.5:1。
3. **顏色不可單獨承載意義**。狀態、漲跌、分類都要另外配文字或符號。
4. **手機先看一次**。這七套裡有四套（1、3、4、7）在窄螢幕會出問題：
   多欄網格、並排圖文、寬字距標題都需要明確的斷點規則。
5. **算繪出來看**。改完一定要真的截圖確認，桌機與手機都要。
